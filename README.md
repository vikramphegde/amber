# Ember

A small, scripted prototype for a kinder landing after doomscrolling. It runs entirely in the browser; choices stay in page memory and are not sent to a server.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. Open this folder in VS Code.
3. In the integrated terminal, run:

   ```sh
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite.

Use `npm run build` to create a production build in `dist/`.

## Prototype scope

The session is scripted and uses a small, human-written offline action library. There is no `/chat` endpoint, model call, database, analytics, or API key in this milestone. The safety-aware server and persistent measurement are later milestones.
